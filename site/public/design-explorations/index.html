Three directions for Rokumentarni dani

Each is a full landing page mockup. Open any one in a new tab and scroll. Then come back and tell Claude which feels right (or which bits to mash together).

  • Direction 01

    Cinema
    Hall

    Dark editorial

    A24 / Criterion energy. Deep blacks, warm amber, big serif display, film-grain texture, festival photos as posters. Slow, premium, cinematic.

    Cormorant Garamond · Inter · JetBrains Mono

  • Direction 02

    Magazine
    Poster

    Bold print

    Wallpaper magazine / Pentagram poster. Cream paper, brick-red accent, oversized type as the visual hero, asymmetric grid, program-as-table. Editorial and confident.

    Fraunces · Space Grotesk · Space Mono

  • Direction 03

    Concert
    Energy

    Vibrant maximalist

    Gig-poster / Spotify / club-night feel. Dark base with neon, cyan, hot-pink accents, animated mesh gradients, marquee tickers, sticker UI. Loud, young, music-forward.

    Bricolage · Instrument Serif · DM Mono

Notes for the brainstorm

  • All three use the same content (same films, same news, same dates) so you can compare design only.
  • All three are responsive — try resizing the window.
  • Hero photos pull from your existing /media/2018/06/ folder.
  • You can mix-and-match — e.g. typography from 02 with the dark base of 01, or the marquee from 03 inside 01.
