Internal · Pixel divider styles

Pick a divider.

Six variants. All use square pixel cells (no more stretched dashes). Tell Claude which one to ship — different sections can get different variants if you want a rhythm of styles down the page.

01 · Sparse film-strip · current default

Random scattered cells, ~40% lit, mostly bone with the occasional cyan dot. Reads as film-strip perforation.

02 · Dense

Tighter, ~75% lit. More structural, almost a barcode. Stronger visual punctuation between sections.

03 · Dots

Every cell rendered as a tiny dot, regular pitch. Subtle, calm — almost a pinstripe.

04 · Punchcard

Regular pattern (every 3rd cell lit). Mechanical, grid-like — ticket-stub or punchcard feel.

05 · Equalizer (taller)

Same cells but taller and varying heights — reads as a static audio EQ. Most "music-y" of the bunch.

06 · Fade ends

Sparse pattern but with the left and right edges fading to transparent — divider feels like it floats.

07 · Big cells (10px)

Same sparse pattern but 10×10 cells instead of 6×6. Reads more like a poster, less like background detail.

08 · Tiny cells (3px)

Half the size — feels like display noise / fine grain. Almost invisible at glance, only noticed when scrolled past.

Tell Claude which numbered variant to ship — or whether different sections should rotate through several.
